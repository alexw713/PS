## Notes

- OnlyFans handles are marked **medium** because Wikidata records the username but live ownership / redirects were not re-authenticated in a logged-in session.
- Admin create/edit and the performers API accept `imageUrl` so portraits can be updated without a code change.
- Re-run `npx prisma db seed` (or your compose seed step) after deploy so existing DB rows pick up the new `imageUrl` and link fields.
